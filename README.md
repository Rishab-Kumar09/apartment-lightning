# Apartment Lightning

The agent that never misses a new apartment listing.

Tell it what you want — *"1-bedroom under $1,600, 30 minutes from downtown Austin, need parking, cats OK"* — and it watches property-management sites for new listings, scores each one against your criteria, and prepares an application the moment a match appears using a [Solari](https://getsolari.com) cloud browser. It never submits on its own: it fills what it safely can, flags anything sensitive (SSN, income docs, etc.) for you to fill in by hand, and waits for you to click **Submit**.

**Status: work in progress.** Full README (architecture, setup, demo) lands once the core pipeline is done — see open tasks in this repo for current progress.

Built on [Solari](https://github.com/solari-sdk/solari-cookbook).
